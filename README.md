# MiniGames

A single-page web application with a game library, built with TypeScript, HTML and SCSS without frameworks. RS School qualifying stage project.

## Tech stack

- TypeScript
- Vite
- SCSS
- ESLint, Prettier, Husky

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — run ESLint
- `npm run format` — format code with Prettier
